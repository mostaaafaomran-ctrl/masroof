# Masroof

Student allowance tracker in EGP.

**Live: https://mostaaafaomran-ctrl.github.io/masroof/**

Set your monthly allowance, log expenses, and see how much you can safely spend per day.

## Features

- Safe-to-spend-per-day number from what is left and days left
- Category limits with bars, and a runs-out-early warning
- Monthly view, CSV export, Arabic and English
- Saved in your browser only (localStorage)

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Privacy

Everything runs in your browser. Nothing is uploaded and there is no account.
